# Build your own cockpit around MT5

You cannot reskin, rebrand or replace MetaTrader 5 itself, but you can legally build a TradingView-like interface around an unmodified MT5 terminal, and every piece you need already exists. MQL5 is MT5's built-in C++-like language for Expert Advisors, indicators, scripts, libraries and services ([MetaTrader 5](https://www.metatrader5.com/en/automated-trading/mql5); [MQL5 Reference](https://www.mql5.com/en/docs/mql5_guide)). It gives you two sanctioned ways to get data and orders out of the terminal: the official MIT-licensed `MetaTrader5` Python package, and an EA you write yourself that talks to a local app over sockets, HTTP, files or named pipes ([PyPI](https://pypi.org/project/MetaTrader5/); [MQL5 docs](https://www.mql5.com/en/docs/files/FileOpen)). The client-terminal licence reportedly prohibits modification, derivative works and reverse engineering. Broker-side APIs (Manager, Server, Gateway, Web) and white labels are only for licensed brokers ([Finance Magnates](https://www.financemagnates.com/forex/technology/3rd-party-developer-gets-red-card-as-metaquotes-re-acts/); [MetaQuotes](https://metaquotes.net/en/metatrader5/brokers)). On the charting side, TradingView's Advanced Charts and Trading Platform libraries are not licensed for personal use, so Lightweight Charts (Apache 2.0) is the only TradingView library a private tool can use ([TradingView FAQ](https://ar.tradingview.com/charting-library-docs/latest/resources/Frequently-Asked-Questions)). The recommended stack has six layers: MT5 on Windows, a Python bridge (FastAPI plus WebSocket), a React and Lightweight Charts v5 front end, SQLite storage, an MCP server for Claude, and n8n calling the same local API. Every order passes through one risk gate that enforces the same SL, spread and max-risk rules as the gold EA. Two open-source projects released in October 2026 already prove the pattern, and you can borrow their code.

Most citations below come from **search-engine extracts** of those pages, not full-page reads. That includes the official MQL5 page this report analyses, the TradingView licensing FAQ and the MT5 EULA wording. Only PyPI and some GitHub repo pages were read in full. Check exact terms on the live pages before you rely on them, especially licensing.

## MQL5 gives you five program types and a full chart-level UI toolkit

The official page presents MQL5 as an object-oriented language with "the highest calculation speed" and C++-like syntax. You write and debug code in MetaEditor, which includes a Wizard that generates starter robots, and you test it in the Strategy Tester. Finished apps can be bought on the Market, and custom work can be commissioned through Freelance ([MetaTrader 5](https://www.metatrader5.com/en/automated-trading/mql5); [MetaQuotes services](https://www.metaquotes.net/en/services)). The program types matter for architecture, because each one has different permissions:

| Type | Trades? | Network I/O? | Threading | Role in your setup |
|---|---|---|---|---|
| Expert Advisor | Yes | Yes (WebRequest, sockets) | Own thread | Strategy engine and/or bridge to your app |
| Custom indicator | **No** | **No** (error 4014) | Shared thread per symbol | On-chart visuals only |
| Script | Yes | Yes | Own thread | One-off utilities |
| Service | Yes | Yes | No chart attached | Background bridge, but no UI |
| Library | n/a | n/a | n/a | Shared functions |

Sources for the table: [MQL5 Reference](https://www.mql5.com/en/docs/mql5_guide); [WebRequest docs](https://www.mql5.com/en/docs/network/webrequest).

Inside the terminal, customisation is extensive but limited to charts. MQL5 can set every chart colour and property and apply saved templates ([CChart ApplyTemplate](https://www.mql5.com/en/docs/standardlibrary/cchart/cchartapplytemplate)). It can draw pixel-anchored buttons, edit boxes and panels, and even embed one chart inside another with `OBJ_CHART` ([MQL4/MQL5 object reference](https://docs.mql4.com/constants/objectconstants/enum_object_property); [MQL5 features](https://docs.mql4.com/mql5_language/mql5_functions/mql5_customsymbols)). It can also render arbitrary anti-aliased graphics through **CCanvas**, plot graphs with CGraphic, and draw in 3D with DirectX ([Build 1495 notes](https://www.metatrader5.com/en/releasenotes/terminal/1398); [DirectX tutorial](https://www.mql5.com/ko/articles/10425)). For windowed panels with caption, minimise and close buttons, the Standard Library provides `CAppDialog`. It has no table or grid control, though, and panels break on timeframe changes unless you handle their lifecycle carefully ([MQL5 blog](https://www.mql5.com/en/blogs/post/776908); [MQL5 forum](https://www.mql5.com/en/forum/158433)). `OnChartEvent` passes mouse, keyboard and object-click events to your code, and `EventChartCustom` lets programs message each other across charts ([Chart events](https://www.mql5.com/en/docs/constants/chartconstants/enum_chartevents)). Custom symbols fed by `CustomTicksAdd` and `CustomRatesUpdate` can bring outside data into native MT5 charts ([MQL5 book](https://www.mql5.com/ja/book/advanced/custom_symbols/custom_symbols_create_delete)).

The practical ceiling follows from this. A dark, one-click "trading cockpit" with a risk calculator and custom-drawn levels is fully buildable inside MT5. The terminal's own menus, toolbars, Navigator, Market Watch and order dialog are not. No retrieved source documents an MQL5 API for changing those native windows. Treat that conclusion as strongly inferred but not verified, because the full reference could not be read. The light/dark theme is a terminal setting that MetaQuotes improved in builds 5640 and 5830 in 2026, not something MQL5 controls ([Build 5640](https://www.metatrader5.com/en/releasenotes/terminal/2430); [Build 5830](https://www.metatrader5.com/en/releasenotes/terminal/2437)). If you want a genuinely TradingView-like experience, with fluid drawing tools, multiple layouts and a modern UI, it has to live outside the terminal.

## The legal line is "talk to MT5," never "modify MT5"

The boundary is sharp. According to a MetaQuotes notice quoted by Finance Magnates, the MT4/MT5 client licence forbids "modification, translation, creating derivative works, reverse engineering, decompiling, disassembling or hacking." MetaQuotes has also objected to DLLs and EXEs being injected into distributions ([Finance Magnates](https://www.financemagnates.com/forex/technology/3rd-party-developer-gets-red-card-as-metaquotes-re-acts/); [Finance Magnates](https://financemagnates.com/forex/brokers/metaquotes-warns-brokers-about-illegal-plugins)). MetaQuotes enforces this. It won a court injunction against PFSoft over alleged IP misuse, and reportedly terminated prop-firm platform licences over breaches of its "grey label" terms ([Finance Magnates](https://www.financemagnates.com/forex/brokers/breaking-metaquotes-obtains-injunction-pfsoft-patent-misuse/); [Finance Magnates](https://financemagnates.com/forex/prop-trading-firms-renaissance-cutting-us-clients-integrating-new-trading-platforms)). The full EULA text could not be fetched, so this wording is secondhand.

Several routes that look like shortcuts are closed to a retail trader. The Manager, Server, Gateway and Web APIs are broker-side interfaces that need a trade-server licence or manager credentials ([FundedTrading](https://fundedtrading.com/platform-provider/metatrader-5/); [PyPI MT5Manager](https://pypi.org/project/MT5Manager/5.0.3906)). White labels go through licensed providers. PrimeXM quotes $2,000 setup plus $3,000 per month, and B2BROKER estimates $5k–30k setup plus $1k–10k per month. MetaQuotes stopped issuing new white labels in October 2022 ([PrimeXM](https://primexm.com/mt5-white-label-pricing); [B2BROKER](https://b2broker.com/news/mt5-white-label-costs/); [FX News Group](https://fxnewsgroup.com/forex-news/retail-forex/fx-week-in-review-metatrader-removed-from-app-store-mt4-mt5-white-labels-stopped-ovalx-replaces-ceo/)). pymt5 drives the web terminal through a reverse-engineered WebSocket protocol ([pymt5 docs](https://pymt5.readthedocs.io/en/latest/python_api_detailed_comparison.html)). That puts it in the zone the licence prohibits, and it can break whenever MetaQuotes changes the protocol. Avoid it. Keep "MetaTrader" and "MT5" out of your app's name too. MetaQuotes has fought over domain names before ([Finance Magnates](https://www.financemagnates.com/forex/brokers/metaquotes-loses-in-a-battle-over-metatrader-com-domain-name/)), so the trademark risk is real, although this point is inferred rather than documented.

Three platform rules restrict choices that are otherwise allowed. First, **DLLs are banned on the MQL5 Market and on MQL5 VPS** ([Market rules](https://www.metatrader5.com/zh/terminal/help/market/market_sell.md); [MQL5 forum](https://www.mql5.com/en/forum/441752/45018388)), so a ZeroMQ bridge that depends on a DLL would rule out MetaQuotes' own VPS. Second, since build 4570, **an account with a signal subscription blocks all MQL5 trading functions** ([Build 4570](https://www.metaquotes.net/en/metatrader5/news/5456)), so you cannot copy a signal and run your gold EA on the same account. Third, **WebRequest does not run in the Strategy Tester**, and forum reports say sockets fail there too ([WebRequest docs](https://www.mql5.com/en/docs/network/webrequest); [MQL5 forum](https://www.mql5.com/en/forum/349124)). Your EA's signal logic must therefore run with no external app connected, or you will not be able to backtest it.

TradingView adds a parallel restriction on the charting side. Advanced Charts is free only for public, non-paywalled projects. The FAQ says that neither Advanced Charts nor Trading Platform is provided "for personal use, hobbies, studies, or testing" ([TradingView docs](https://in.tradingview.com/charting-library-docs/latest/introduction/); [TradingView FAQ](https://ar.tradingview.com/charting-library-docs/latest/resources/Frequently-Asked-Questions)). Older forum posts suggest people once downloaded it freely, but the current FAQ supersedes them. A private Windows app counts as personal use, so **Lightweight Charts is the TradingView option you can use**. It requires visible TradingView attribution and a link, which the `attributionLogo` option provides ([GitHub](https://github.com/tradingview/lightweight-charts)). TradingView also restricts its own platform data to display-only personal use ([TradingView policies](https://in.tradingview.com/policies)), so do not scrape TradingView prices into your automated system. Use MT5 broker data instead.

## Four sanctioned data paths exist, and the Python package is the right start

| Route | Real-time model | Runs where | Licensing / risk | Fit for Bijoy |
|---|---|---|---|---|
| Official `MetaTrader5` Python package | Polling (no push API) | Windows x64 only, terminal must be running | MIT, fully sanctioned | **Start here** |
| Your own EA bridge (native sockets / WebRequest / files / pipes) | Event push from `OnTick` / `OnTradeTransaction` | Windows terminal | Sanctioned; DLL-free unless you use ZeroMQ | Upgrade path for latency |
| MetaApi cloud | WebSocket streaming | Any OS, vendor-hosted | First account free, then billed; third party holds your password | Not needed for a local app |
| Broker web terminal in an iframe | UI only, no programmatic access | Browser | Broker-licensed | Manual trading tab at most |

Sources for the table: [PyPI](https://pypi.org/project/MetaTrader5/); [pymt5 comparison](https://pymt5.readthedocs.io/en/latest/python_api_detailed_comparison.html); [MetaApi FAQ](https://metaapi.cloud/docs/client/faq/); [MetaTrader 5 news](https://metatrader5.com/en/news/2253).

The Python package (v5.0.6231, released 27 September 2026) attaches over local IPC to a running, logged-in desktop terminal. It mirrors MQL5 functions such as `copy_ticks_from`→CopyTicks, `symbol_info_tick`→SymbolInfoTick and `order_send`→OrderSend ([PyPI](https://pypi.org/project/MetaTrader5/); [MQL5 book](https://www.mql5.com/de/book/advanced/python/python_funcs_overview); [go-mt5 docs](https://pkg.go.dev/github.com/mukbeast4/go-mt5)). It has no callback API, so live data means polling, and backfilling with `copy_ticks_from` to catch ticks missed between polls. That suits H1/M15 gold and oil work. If you later need tick-exact push, write an EA bridge. MQL5's native `Socket*` functions handle raw TCP to a whitelisted local address with no DLL, up to 128 sockets per program ([SocketCreate](https://mql5.com/ko/docs/network/socketcreate); [SocketConnect](https://www.mql5.com/ko/docs/network/socketconnect)). Skip the old Darwinex ZeroMQ connector, which targeted MT4 and has been archived since February 2022 ([gittrend](https://gittrend.io/repo/darwinex/dwx-zeromq-connector)). MetaApi solves a problem you don't have, since you will run the terminal locally anyway. Adding an account to it also "exposes your MT account password" to a vendor, by MetaApi's own account ([MetaApi FAQ](https://metaapi.cloud/docs/metastats/faq/)).

Two caveats are documented only in forum threads. `copy_ticks_range` is reported to fail on multi-year ranges ([Forum 391710](https://www.mql5.com/en/forum/391710)). Tick timestamps may come back in broker server time rather than UTC, with one report of about 3 hours ahead ([MQL5 forum](https://www.mql5.com/en/forum/517065)). Normalise all times to UTC in the bridge, then convert to IST for display.

## Two October 2026 projects already prove the full stack

For the chart, use Lightweight Charts v5. It is about 17.6k stars, Apache 2.0, and 35 kB at its base. It added **multi-pane support** for oscillators and a primitives/plugin API for drawings and annotations, but it ships no drawing tools or indicators of its own ([TradingView blog](https://www.tradingview.com/blog/en/tradingview-lightweight-charts-version-5-50837); [GitHub](https://github.com/tradingview/lightweight-charts)). Community packages fill the gap. lightweight-charts-drawing claims 68 tools at v0.1.1, and lightweight-charts-indicators claims 1,713 indicators including Pine ports ([GitHub](https://github.com/deepentropy/lightweight-charts-drawing/releases); [GitHub](https://github.com/deepentropy/lightweight-charts-indicators)). Their quality is unaudited. The strongest free alternative is KLineChart (Apache 2.0, built-in indicators and drawing models), which offers more out of the box at the cost of the TradingView look ([GitHub](https://github.com/klinecharts/KLineChart)). Highcharts Stock and SciChart are free only for non-commercial use, and SciChart's free tier is watermarked ([SciChart docs](https://www.scichart.com/documentation/js/v4/user-manual/licensing-scichart-js/getting-started-for-free/)).

Two very new MIT-licensed projects are the best reference code. **CheapTrader** matches your planned stack almost exactly: the MT5 Python package behind FastAPI REST plus WebSocket on 127.0.0.1, a React/Vite and Lightweight Charts v5 front end, and a SQLite bar cache. Its Python indicators run sandboxed, it supports drawing tools that place trades, SL/TP you drag on the chart, and bar replay. It ships as a single PyInstaller exe that opens an Edge app-mode window. Its feed, reads and orders run in separate processes so a slow terminal call cannot stall the stream, and live orders are off by default. One caveat: the README says a checked-in `.env` turns live orders on, so verify that before running it ([CheapTrader](https://github.com/REDIN14/CheapTrader)). **Better Charts** takes the EA-bridge route, with an MQL5 EA on 127.0.0.1:8765 using a private token and a Tauri 2 shell. Its execution-safety design is worth copying: account binding, reconciliation, durable execution journals, no automatic retries, and `OrderCheck` before every send ([Better Charts](https://github.com/tomek-r/better-charts)). Both have 0 stars and were tested on demo accounts only, so treat them as blueprints, not dependencies. For a desktop shell, the cheapest option is FastAPI plus a browser app window. Tauri 2 uses Windows' built-in WebView2 and needs far less memory than Electron (172 MB versus 409 MB in one benchmark) ([pkgpulse](https://www.pkgpulse.com/guides/electron-vs-tauri-2026)).

For Claude, several MCP servers already wrap the MT5 Python package. The largest are ariadng/metatrader-mcp-server (831 stars) and Qoyyuum/mcp-metatrader5-server (232 stars). vincentwongso/mt5-trading-mcp adds a consent and audit layer for trades, and PHUICMT/mcp-mt5 compiles, deploys and backtests EAs ([ariadng](https://github.com/ariadng/metatrader-mcp-server); [Qoyyuum](https://github.com/Qoyyuum/mcp-metatrader5-server); [vincentwongso](https://github.com/vincentwongso/mt5-trading-mcp); [PHUICMT](https://github.com/PHUICMT/mcp-mt5)). None of their code was audited. The research found no sources on dedicated n8n–MT5 integrations, so the n8n design below is plain HTTP and webhooks against your own API, which needs no special connector.

### Recommended step-by-step path

1. **Fix the ground rules.** Use an unmodified MT5 terminal on your Windows PC, a demo account first, and no signal subscription on any account the EA trades. Use Lightweight Charts with the attribution logo visible, and keep MetaTrader branding out of the app name.
2. **Keep the gold EA self-contained.** Its entry, SL, TP, spread filter, max risk and magic number must work with no external connection, so the Strategy Tester can backtest it (WebRequest and sockets don't run in the tester). Your app observes and assists. It is not a dependency of the strategy.
3. **Stand up the Python bridge (week 1).** Install `MetaTrader5` and FastAPI on Windows. Expose REST endpoints for symbols, bars, positions and history, plus a WebSocket that pushes polled ticks and bar updates. Run the feed, reads and orders in separate processes, as CheapTrader does. Bind to 127.0.0.1 only and normalise timestamps to UTC.
4. **Store data locally.** Cache bars and ticks in SQLite (or Parquet for long tick history) and log every signal and order to a journal table. The same store will later back your trade-journal skill.
5. **Build the chart UI (weeks 1–2).** Use React plus Lightweight Charts v5. Start with candles, a watchlist (XAUUSD, WTI/Brent, majors), an oscillator pane, position and SL/TP price lines, and a session-time overlay in IST. Add drawing tools from the deepentropy package, or write your own primitives.
6. **Compute indicators in Python, once.** Write the entry logic as Python functions on the bridge, and keep it identical to the Pine indicator and the MQL5 EA, as `.claude/rules/code-standards.md` requires. Push the results to the UI as markers or series, and reuse the same code for offline backtests.
7. **Add order entry behind one risk gate (week 3, demo only).** Keep live trading off by default with an environment flag. Reject any order without an SL, above max risk percent, or above max spread, and run `OrderCheck` before every send. Never retry automatically. Journal and reconcile every fill, following Better Charts.
8. **Connect Claude via MCP.** Either adopt an existing MT5 MCP server or write a thin MCP wrapper over your own REST API, which is preferable because the risk gate stays in one place. Give it read-only tools by default (bars, levels, positions, journal) and require your confirmation for any trade.
9. **Wire n8n to the same API.** Use it for scheduled market-structure checks, high-impact news alerts (NFP, CPI, FOMC, EIA), and posting signals to Telegram. n8n gets no order rights that bypass the risk gate.
10. **Package and harden.** Ship as a PyInstaller exe that opens an Edge app window, or wrap it in Tauri 2 later. If the EA must keep running through London and New York hours (roughly 12:30–21:30 IST and 17:30–02:30 IST, shifting with DST), move the terminal to a Windows VPS. MQL5 VPS works only if everything stays DLL-free, and its data is lost if the subscription lapses ([MQL5 forum](https://www.mql5.com/en/forum/166673/4839283)).
11. **Upgrade only if needed.** If polling latency hurts entries, replace the feed process with an EA socket bridge (native `Socket*`, no DLL) that pushes from `OnTick` and `OnTradeTransaction`. Keep the rest of the stack unchanged.

## Conclusion

The question changes once you see the constraints. A "custom MT5" is not a modified terminal. It is MT5 demoted to execution engine and data source, with your own software owning the screen, the storage and the intelligence. That split also improves the trading. Because the backtestable EA stays self-contained while the UI, Claude and n8n sit outside it, a bug in the dashboard cannot corrupt the strategy, and one risk gate becomes the only path to the broker for every client: chart clicks, AI suggestions and automations. The real risks are operational, not legal: unaudited 0-star dependencies, an AI or workflow tool with order rights, and Python, Pine and MQL5 versions of the signal drifting apart.

Open items to verify before committing: the live wording of the MT5 EULA and TradingView's FAQ (both read only from search extracts), the maintenance status and code of the MCP servers and Lightweight Charts add-ons, and whether your broker's terms allow automated or third-party access. The CheapTrader-style MVP is a realistic multi-week build for one developer. That fits a separate track behind the 29 October EA and indicator targets rather than competing with them.
