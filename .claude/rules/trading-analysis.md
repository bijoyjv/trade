# Trading Analysis

- Instruments in scope: gold (XAUUSD), oil, forex.
- Analyze top-down: higher timeframe bias first, then entry timeframe.
- Every trade idea states: bias, entry zone, stop loss, target(s), risk:reward, and invalidation.
- State the timeframe and data source for any level quoted. Never invent prices; if live data isn't available, say so.
- Flag high-impact news events (e.g., NFP, CPI, FOMC, EIA inventories for oil) that could affect a setup.
- Analysis is decision support, not a guarantee. Bijoy makes the final call.
